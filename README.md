# Website NU Pandansari

> Platform digital resmi Pengurus Ranting Nahdlatul Ulama (PRNU) Desa Pandansari untuk mempublikasikan berita, dokumentasi galeri kegiatan, serta informasi struktur organisasi kelembagaan dan Badan Otonom (Banom).

---

## 🚀 Fitur Utama
* **Manajemen Berita & Pengumuman**: Publikasi artikel dan kegiatan ranting secara dinamis.
* **Galeri Dokumentasi**: Arsip foto kegiatan lengkap dengan deskripsi interaktif.
* **Struktur Organisasi Terpusat**: Direktori pimpinan dan daftar anggota kelembagaan/Banom (NU, Muslimat, Fatayat, Ansor, Banser, IPNU, IPPNU).
* **Fitur Cetak ID Card PDF**: Modul admin untuk menghasilkan dan mengunduh kartu identitas pengurus/anggota dalam format PDF.
* **Panel Admin Khusus**: Dashboard manajemen data yang dilindungi sistem autentikasi dan hak akses peran (*Role-Based Access Control*).

---

## 🛠️ Tech Stack
* **Backend**: Laravel 13 (PHP 8.5)
* **Frontend / Styling**: Tailwind CSS (Brutalist-inspired clean design)
* **Database**: MariaDB / SQLite
* **Library Pendukung**: Spatie Permission (Role & Permission), BarryVDH DomPDF (PDF Generator)
